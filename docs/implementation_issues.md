# Issue tracking

Issue tracking for this project has moved to **GitHub Issues**:

https://github.com/runlevel0/paper_marker/issues

## Legacy IDs

Migrated items use `[ISSUE-NNN]` in the GitHub issue title. For this migration, **GitHub issue number equals the legacy ID** (for example, `[ISSUE-017]` is issue **#17**).

Mapping file: [`docs/archive/github_issue_map.json`](archive/github_issue_map.json)

## Archives

- Pre-migration ledger (ISSUE-001–016): [`docs/archive/implementation_issues_ledger_pre_github.md`](archive/implementation_issues_ledger_pre_github.md)
- Recovered lost entries (ISSUE-017–022): [`docs/archive/implementation_issues_lost_entries_recovered.md`](archive/implementation_issues_lost_entries_recovered.md)

## Workflow

- Open new work via the [implementation task template](https://github.com/runlevel0/paper_marker/issues/new?template=implementation_task.yml).
- Reference issues in PRs with `Fixes #N` or `Related to #N`.
- Agents and contributors: use `gh issue list`, `gh issue view`, and `gh issue create` (see `AGENTS.md` and `CONTRIBUTING.md`).

Do not add new ledger entries to this file.
